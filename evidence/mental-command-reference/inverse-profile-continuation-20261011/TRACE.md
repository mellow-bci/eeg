## Proven inverse profile dispatch

`jsonObjectToProfile` begins at 0x100b16cfc (`profile-import.txt`). It constructs an EmoProfile named `default`, iterates JSON object properties, obtains the property key and actual JSON type (0x100b16dc0/dd0). Numeric values go through concreteDouble(default 0) then EmoProfile::set(double) at 16dfc/e08; strings through concreteString then a string QVariant at 16e28/e44. For objects it tries **toMatrix first** (16ec4), **toGaussianAlgebra second** (17004), then **toClassifier third** (1709c). The first converter whose flag is true is stored under the original property key. Dispatch is shape-based, not restricted to the cognitiv-classifier key. If all object converters reject, it logs `unexpected object` at 17108 and proceeds without setting that property. Other JSON kinds log `unexpected type` at 16f14 and proceed. This proves useful profile interchange behavior, not encrypted-file loading or training acceptance.

## Matrix schema and finite implementation

`toMatrix` 0x100b11fd4 requires exactly three keys (1201c), finds `rows`, `cols`, `elements`, then requires JSON types numeric/numeric/array (124c8,1250c,1253c). Missing, extra or wrong-type keys set false and return default empty Matrix (1217c..188,12404). Dimensions use Qt toInt(default 0). Both nonzero dimensions require a nonempty elements array (122f0..12300); storage is initially **zero-filled** (12304..310). It loops over array size rather than matrix size (12390..3c8): a shorter array leaves zero tail; nonnumber entries become zero through concreteDouble(default 0), 123a8. Writes use linear Matrix::operator()(int), 123bc. Linear accessor 102135130 checks bounds at 144..148 and advances by index*8 at 17c. Oversized arrays therefore hit an exceptional helper, not a normal rejected-schema result. If either dimension is zero, it asserts both dimensions zero and array empty (123cc..3dc).

`ReferenceProfileCodec.decodeMatrix` reproduces this within finite nonnegative integral Int32 dimensions and a caller-supplied maximumElements. Exceptional shapes become explicit errors; fractional/out-of-range dimensions are unsupported rather than guessed Qt edge conversion. Finite numeric elements only. Schema acceptance remains separate from data/model validity. Returned elements use the now-proven row-major equation: Matrix::operator(row,column) at1021350d0 loads cols from+0x1c and MADD computes cols*row+column at1021350dc; mutable counterpart102134fb0 matches. rows()/cols() return+0x18/+0x1c. Matrix::vector returns its base storage identity (102135058/05c); rawData loads+8. The non-square independent fixture verifies fromRows/rowValues without a symmetry-only test.

## Matrix/Armadillo bridges

`toArmadilloMatrix` 10212cfc4 transposes the Matrix (cfe4), reads its rawData (cfec), and constructs an Armadillo matrix with original rows and cols (d018..020). `fromArmadilloMatrix` 10212d080 calls expression materialization helpers 100b2110c/100b213cc then constructs Matrix using original dimensions and expression raw storage (d10c..11c). Full helpers remain a layout dependency for numeric runtime bridging.

`toArmadilloUVec(Matrix const&)` 10212d1a4 accepts an empty matrix or one with rows==1 OR cols==1 (d204..218). It iterates linear elements and executes **FCVTZU** (d2b8), producing an unsigned column vector. Invalid matrix shape is exceptional. The implementation supports finite nonnegative exactly representable integer values up to 2^53-1; negative/fractional/saturation cases are explicitly unsupported. This is narrower than the instruction's full hardware behavior, not an invented rounding rule.

Matrix JSON export's parallel mapping helper 100b1735c allocates a QtConcurrent worker and calls 100b17418,100b19ba8,100b19e6c; full mapper scheduling/mapping implementation remains untraced. fromArmadilloUVec constructs Matrix(n,1,0) at10212d474..47c, then UCVTF each integer and writes linear position49c..4a4; typed indices export uses the same n×1 shape and numeric conversion. The typed independent envelope uses the proven Matrix schema; it is not claimed to reproduce the vendor asynchronous exporter implementation or a vendor database byte stream.

Both counts use Qt toInt(default 0), then **SXTW** into64bit storage (16154/158 and161d0/d4). `ReferenceProfileCodec` exposes a full typed classifier envelope and nested schema flag, but does not wire acquisition, independent training or scoring.
